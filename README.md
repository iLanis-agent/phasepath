# Phasepath 1.0 test build

Move one step or wait. Each successful action flips cyan/0 to amber/1 or back. Enter only gates matching the phase before that move. Gate checks apply on entry, so standing on a gate after the flip is safe. Blocked attempts do not flip phase. Reach the outlined signal receiver. Twelve paths, unlimited undo/reset and level selection.

Native Java/Canvas, Android8+ API26, target35. GG007 icon/menu/studio link/privacy. Saved path palette, direction-label setting and completion marks. Offline, no permissions/accounts/ads/analytics/third-party SDKs. External browser opens the studio. Clear app data/uninstall removes local records.

## Checks and limits
Actual Java BFS over position and phase validates all12 paths with shortest solutions8-15 moves, including wait actions. Solution, undo, replay and wait checks pass. Native drawing/input adapter navigation/control/settings checks pass, preview pixels inspected. These are not real Android phone runtime/performance tests or phone screenshots. Signed TEST build only, not final or Play published.

## Difference
Position-plus-phase route planning with a wait action, rather than Driftwell's slide-to-stop movement, Twin Dock's paired couriers or Prism Relay's beam trace. Catalog scan found only unrelated timer/astronomy phase matches, no playable overlap. No claim the broad phase-gate puzzle genre is new.

## Build
JDK17, Android platform35/build-tools35.0.0 and zip. Run build.sh with ANDROID_HOME; signing uses private KEYSTORE_PATH, KEYSTORE_PASSWORD_FILE and optional KEY_ALIAS. No signing credentials included.
